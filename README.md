# Feed the Dragon

Pygame ile yazılmış özgün Feed the Dragon oyununun responsive tarayıcı sürümü.

- Masaüstü: Yukarı/aşağı okları veya W/S
- Mobil/tablet: Ekrandaki tuşlar ya da oyun alanında sürükleme
- Özgün görseller, sesler, müzik, skor, can ve hızlanma mekaniği korunmuştur

`feed_the_dragon.py` özgün Python kaynağıdır.
